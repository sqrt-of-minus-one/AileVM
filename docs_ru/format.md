# Структура файла

Структура формата `.lvm` (v0x00.00.01).

## Заголовок

1. 4 байта со значениями `2E 6C 76 6D` (строка `.lvm` в UTF-8).
1. 3 байта — версия формата (`00 00 01`). Значение `00 00 00` всегда некорректно.
1. 1 байт — разрядность, для которой написана программа:
	- `01` — 16 бит;
	- `02` — 32 бита;
	- `03` — 64 бита.
1. N байтов — объём оперативной памяти.
1. N байтов — начальное значение регистров `_BP` и `_SP`.
1. N байтов — начальное значение регистра `_IP`.

## Данные

Оставшийся файл состоит из последовательности блоков, описывающих начальное состояние памяти. Каждый блок включает в себя следующие компоненты.
1. N байтов — адрес в памяти, куда должны быть помещены описываемые блоком данные.
1. N байтов — размер данных, описываемый блоком, в байтах. Может иметь значение 0, в этом случае размер данных явно не определён.
1. N байтов — количество раз, которое данные должны быть повторены в памяти. Отсутствуют, если в качестве размера данных указан 0.
1. Непосредственно данные, которые должны быть помещены в память. Если размер не определён (т. е. указан 0), данными считается всё содержимое до конца памяти.
