# `0x01`

Позволяет получить информацию о виртуальной машине. Результат выполнения зависит от значения регистра `AH`.
- Если `AH` = `0x00`, помещает в регистр `AH` значение, соответствующее разрядности виртуальной машины:
	- `0x01` для x16;
	- `0x02` для x32;
	- `0x03` для x64.
- Если `AH` = `0x01`, помещает в регистры `AX`, `BX`, `CX` и `DX` значения, специфичные для реализации виртуальной машины.
- Если `AH` = `0x02`, помещает в регистры `AX`, `BX` и `CX` номер версии реализации виртуальной машины (соответственно старшую, младшую и патч).
- В остальных случаях инструкция ничего не делает.

## `0000'0000` — `INFO` / `CPUID` / `VMID`

- `(AH == 0x00) ? AH = <разрядоность>`
- `(AH == 0x01) ? AX, BX, CX, DX = <название реализации>`
- `(AH == 0x02) ? AX, BX, CX = <версия реализации>`
