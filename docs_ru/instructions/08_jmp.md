# `0x08`

Осуществляет условный или безусловный переход, изменяя значение регистра `_IP`. Все операнды имеют N-байтный размер, кроме операнда инструкции `RET`, который имеет размер 1 Б (x16) или 2 Б (x32 и x64). Регистр флагов не изменяется.

## `0000'1000_ff00'0000` — `JMP f`

- `_IP = f`

## `0000'1000_ff01'0000` — `CALL f`

- `_SP -= N`
- `[_SP] = _IP`
- `_IP = f`

## `0000'1000_0010'0000` — `RET`

- `_IP = [_SP]`
- `_SP += N`

## `0000'1000_ff11'0000` — `RET f`

- `_IP = [_SP]`
- `_SP += N + f`

## `0000'1000_ff00'0001` — `JNC f` // `JNB f` // `JAE f`

- `!CF ? _IP = f`

## `0000'1000_ff01'0001` — `JC f` // `JB f` // `JNAE f`

- `CF ? _IP = f`

## `0000'1000_ff00'0010` — `JNO f`

- `!OF ? _IP = f`

## `0000'1000_ff01'0010` — `JO f`

- `OF ? _IP = f`

## `0000'1000_ff00'0100` — `JNZ f` // `JNE f`

- `!ZF ? _IP = f`

## `0000'1000_ff01'0100` — `JZ f` // `JE f`

- `ZF ? _IP = f`

## `0000'1000_ff00'1000` — `JNS f`

- `!SF ? _IP = f`

## `0000'1000_ff01'1000` — `JS f`

- `SF ? _IP = f`

## `0000'1000_ff00'0101` — `JNBE f` // `JA f`

- `(!CF && !ZF) ? _IP = f`

## `0000'1000_ff01'0101` — `JBE f` // `JNA f`

- `(CF || ZF) ? _IP = f`

## `0000'1000_ff00'1010` — `JNL f` // `JGE f`

- `(SF == OF) ? _IP = f`

## `0000'1000_ff01'1010` — `JL f` // `JNGE f`

- `(SF != OF) ? _IP = f`

## `0000'1000_ff00'1110` — `JNLE f` // `JG f`

- `(SF == OF && !ZF) ? _IP = f`

## `0000'1000_ff01'1110` — `JLE f` // `JNG f`

- `(SF != OF || ZF) ? _IP = f`

## `0000'1000_ff00'1111` — `JCXZ f`

- `(_CX == 0) ? _IP = f`

## `0000'1000_ff01'1111` — `JCXNZ f`

- `(_CX != 0) ? _IP = f`
